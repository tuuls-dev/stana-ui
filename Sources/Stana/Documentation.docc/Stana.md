# `Stana`

Build retained desktop applications with explicit state and properties-first composition.

## Overview

A component describes one mount. Signals update the properties of retained nodes; builders do not rerun on ordinary state changes. Native windows, text services, drawing, and accessibility are installed behind portable interfaces.
